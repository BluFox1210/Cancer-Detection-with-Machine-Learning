Dataset Information
This project uses three public datasets for breast cancer detection

Dataset 1 - Breast Cancer Wisconsin (Diagnostic)
Source: scikit-learn load_breast_cancer()
This dataset is loaded directly through scikit-learn and does not require a separate download

Dataset 2 - METABRIC gene expression profiles
Source: Kaggle
The dataset is downloaded from Kaggle. Raw data files are not committed to this repository

Dataset 3 - Histopathologic Cancer Detection (PatchyCamelyon)
Source: Kaggle Histopathologic Cancer Detection competition
The dataset is downloaded from Kaggle. Raw image files are not committed to this repository due to their size

See project notebook for the dataset loading and preprocessing instructions.
